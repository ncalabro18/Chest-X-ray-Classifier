Model Evaluation Notes

  • ℹ Threshold selection method - Confirm whether thresholds were optimised on the validation set (Youden's J, F1, or clinical sensitivity target). Thresholds derived from the same split used for reporting will be optimistic; consider a held-out test set for final values.
  • ⚠ Class prevalence not reported - PPV and NPV are highly prevalence-dependent. Include positive-case counts per split for full interpretability (especially for rare classes: Hernia, Fibrosis, Emphysema).
  • ⚠ Confidence intervals absent - AUC point estimates without bootstrapped 95% CIs (or DeLong intervals) are insufficient for regulatory or clinical validation contexts.
  • ⚠ Subgroup / fairness evaluation missing - NIH ChestX-ray14 contains demographic metadata (age, sex). Subgroup AUC stratification is standard practice for chest AI systems prior to deployment.
  • ℹ Multi-label co-occurrence - Per-class metrics are marginal. Consider reporting performance on the most common label combinations (e.g. Effusion + Atelectasis) if downstream use involves multi-finding triage.
  • ℹ NIH label quality caveat - NIH ChestX-ray14 labels are NLP-mined from radiology reports; known label noise (especially for Infiltration, Pneumonia, Nodule) means reported metrics may underestimate true model performance on radiologist-adjudicated sets.
