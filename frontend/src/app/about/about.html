Overview

This classifier is a custom SwinTransformer V2 backbone with a multi-scale feature fusion head, trained on the NIH ChestX-ray14 dataset (CXR8) to detect 14 radiological findings simultaneously from a single posteroanterior or anteroposterior chest radiograph.

The model is split into two microservices - a Python FastAPI classifier running on GPU, and a lightweight web proxy that handles validation and sanitisation before forwarding. All inference uses the exponential moving average of trained weights with four-fold test-time augmentation and per-class temperature calibration. After the backbone gradually unfreezes, stocastic weight averaging is used to improve generalization.

SwinV2 Backbone

The backbone is a Swin Transformer V2 Small initialised from a SimMIM self-supervised pre-training checkpoint. It partitions the image into non-overlapping 4 × 4 pixel patches and processes them through four hierarchical stages of shifted-window multi-head self-attention, progressively merging spatial tokens and expanding channel depth.

Classification Head - SwinWithView

Rather than applying global average pooling to the final stage, the head implements multi-scale feature fusion and class query cross-attention to extract per-class representations sensitive to both fine-grained local features and global context.

Multi-scale fusion

Outputs from Stages 1–3 are projected to 768 channels via a two-layer Conv2d bottleneck (768→192→768 with GELU activation) and spatially pooled to match the Stage 4 resolution (12 × 12 at 384px input). Each early stage is weighted by a learned scalar gate passed through sigmoid, allowing the model to adaptively suppress uninformative scales. The final stage output is weighted by a learned temperature via softplus. All token sequences are concatenated and normalised before attention.

Class query cross-attention

Fourteen learnable class query vectors (one per pathology) attend over the full concatenated multi-scale token sequence via scaled dot-product attention. This allows each class to selectively pool features from whichever spatial locations and scales are most discriminative for that finding - for example, costophrenic angles for effusion, or apical regions for pneumothorax.

View conditioning

The projection type (PA or AP) is embedded into a 32-dimensional vector and passed through an MLP (32 → 128 → 1536) to produce per-class scale (γ) and shift (β) parameters, implementing a Feature-wise Linear Modulation (FiLM) layer. The overall conditioning magnitude is controlled by a learned scalar constrained to [0, 2.0] via sigmoid. This allows the model to account for the geometric and magnification differences between PA and AP acquisitions without requiring separate model weights.

Training

Training uses AdamW with layer-wise learning rate decay (decay=0.8 per stage from head to patch embedding), a linear warmup over the first three epochs, and cosine annealing to a per-group floor of 9% of the base learning rate. The backbone is frozen initially and progressively unfrozen across four scheduled events, each followed by a four-epoch warmup to prevent overwriting pre-trained representations.

Limitations

Label noise

CXR8 labels are mined from radiology report text via NLP and carry an estimated 10–20% error rate depending on finding. This is the primary ceiling on achievable AUC for this dataset regardless of model capacity.

Single-image inference

The model evaluates each image independently with no access to prior studies, clinical history, or laboratory values. Findings that are longitudinally subtle may not be detected.

Distribution shift

Training data originates from a single US academic medical centre. Performance may degrade on images from different scanner manufacturers, acquisition protocols, or patient demographics.

Not a diagnostic tool

Thresholds are calibrated for sensitivity in a screening context and will produce false positives. All predictions must be reviewed by a qualified radiologist before any clinical decision is made.
